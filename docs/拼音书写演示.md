# 拼音书写演示

点读主屏左侧展示词语图片和汉字，右侧展示四线三格。点击卡片、朗读按钮或开启自动朗读后换词，均会在声音实际开始播放时触发逐笔演示。重复点读重新开始；切换词卡、离开点读页或进入录音室时停止旧演示。

书写轨迹使用本地 SVG 中心线路径，包含字母、ü 的两点和声调。占格与笔顺参考[上海青浦区世界外国语学校《汉字和汉语拼音书写规范》](https://qp.shwfl.edu.cn/2021/1101/c1975a7899/page.htm)。自绘路径并非教材原版字形，课堂使用前建议教师复核。

`src/content/pinyinWriting.ts` 定义字形、笔顺及音节分行；`src/components/PinyinWriting.tsx` 负责一次性书写和笔尖演示。音节先写字母，后补声调；带调 i 去点，ü 保留两点。

音频选项新增可选回调 `onPlaybackStart`：

- `playTeacherSpelling`：本地 MP3、家长录音的 `playing` 或语音合成的 `start` 事件触发，每次播放会话只通知一次。
- `playItemNaturally` / `playNaturalWordAudio`：音节队列第一次实际播放时通知。
- 原有 `onStart` 仍表示发起朗读请求，既有调用方式保持兼容。

当前仅将书写起点与音频起点关联，书写按可观察的独立节奏进行，没有音素或逐字时间戳对齐。整段音频结束后，未写完的笔画继续演示直至完成。页面进入后台或系统启用减少动态效果时，直接显示完整字形。

验证方式：全词库字形覆盖；i/ü/声调笔画检查；iPad 横竖屏、分屏及手机布局；实际音频触发、重播、换词取消和减少动态效果检查。真实 iPad Safari 的声音与书写观看体验仍待实机复核。
