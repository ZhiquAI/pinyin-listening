# 🎙 家长自录拼读音频对照指南

欢迎为孩子录制属于爸爸妈妈的最亲切的声音！支持两种添加方式：

### 方式一：在网页点读机中一键自录（最推荐、最简单）
1. 打开点读卡片（iPad 模式或电脑浏览器打开 [http://localhost:5173/](http://localhost:5173/)）；
2. 点击卡片顶部的 **【🎙 录入原声】** 按钮；
3. 允许麦克风权限，点击 **🔴 开始录音**，对着屏幕示范台词读完后点 **⏹ 结束录音**；
4. 点击试听，确认满意后点击 **💾 保存并应用**，卡片立即切换为 **💖 家长原声**。

### 方式二：用手机录音软件批量录制为 MP3 放入目录
如果您用专业录音设备或手机录好了 MP3 文件，可直接按以下文件名将音频保存到项目的 `public/audio/spelling/` 文件夹下（例如 `public/audio/spelling/w6_baba.mp3`），刷新页面系统会自动优先播放您的录音。
