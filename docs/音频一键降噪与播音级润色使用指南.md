# 🎙 家长录音专业母带润色处理器使用指南

本工具专门针对**手机麦克风、iPad 自带麦克风、家用耳机录音**产生的常见声学缺陷设计，通过自动化专业 DSP 链路，将家庭普通录音瞬间提升至**专业播音录音棚质感**。

---

## 🛠 5 大专业级母带声学处理链路

1. **85Hz 低频高通切除（Highpass Filter）**：
   - 彻底切除手持震动、手机晃动、呼吸直扑麦克风产生的低频气流“轰轰”与喷麦爆破（Plosive $b, p$ 爆破音）。
2. **专业 De-esser 齿音平滑器**：
   - 针对拼音教学中大量的声母（$s, c, z, sh, ch, zh$），智能压制高频刺耳嘶嘶声，保护孩子听力。
3. **FFT 频域自适应降噪（afftdn）**：
   - 实时跟踪房间背景噪声谱，平滑抹除房间底噪、空调风声、电脑风扇声与环境白噪音。
4. **2.8kHz 黄金人声频段雕琢（Presence EQ）**：
   - 提升拼音声调调值与发音清晰度，让人声通透亲切、富有磁性。
5. **EBU R128 国际广播级响度统一（Loudness Normalization）**：
   - 采用标准双遍响度算法，将所有录音精准对齐到 **`-16 LUFS`（真峰值 `-1.5 dBFS`）**。
   - 保证不管离手机远近、读得大声或小声，每个词播放出来的**音量全部整齐划一、饱满一致**。

## 🚀 常用操作示例

脚本已放置在项目的 `scripts/enhance_audio.py` 中，支持直接在终端执行：

### 1. 润色单个录音文件
把手机传到电脑上的一个录音（例如 `baba.m4a`）处理为高质量播音级 MP3：
```bash
python3 scripts/enhance_audio.py baba.m4a -o w6_baba.mp3
```

### 2. 批量处理整个文件夹（最常用）
把手机录好的一整个文件夹的音频一次性全部处理，并直接输出到项目的拼读库目录：
```bash
python3 scripts/enhance_audio.py ~/Downloads/我的拼音录音/ --out-dir ./public/audio/spelling/
```

### 3. 选择不同处理预设
- **默认播音棚模式（推荐）**：
  ```bash
  python3 scripts/enhance_audio.py input.wav --preset studio
  ```
- **强力降噪模式（如果房间有明显的窗外车声或风扇大风）**：
  ```bash
  python3 scripts/enhance_audio.py input.wav --preset aggressive
  ```
- **温和模式（如果是在安静房间里用好耳机录的）**：
  ```bash
  python3 scripts/enhance_audio.py input.wav --preset gentle
  ```

## 💡 录音操作温馨小建议
- 手机放置在离嘴巴 **15～20 厘米** 处最佳（大约一捺的距离）；
- 录音时让气流**斜着吹向手机侧边**，避免正对底部话筒直吹，配合本脚本的防喷算法，效果立竿见影！
